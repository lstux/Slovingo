# Firmware Slovingo (LilyGo T-HMI)

Projet PlatformIO ESP32-S3 (à venir).

Cible : LilyGo T-HMI (ESP32-S3R8, 16 Mo de flash, 8 Mo de PSRAM, écran ST7789V 320x240, tactile résistif, microSD).
Distribution : fichier `.bin` à copier sur la carte SD et à installer depuis le Launcher.

Premier jalon : affichage et calibration tactile, Wi-Fi, téléchargement du JSON d'un cours, affichage d'un exercice.
