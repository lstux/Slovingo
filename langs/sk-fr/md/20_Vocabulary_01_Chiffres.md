# 🇸🇰 Chiffres de 0 à 20 en slovaque

Les chiffres de base à apprendre d'abord. C'est la fondation — tous les autres nombres s'en construisent.

---

## 0 à 10

| Chiffre | Slovenčina |
|---:|---|
| 0 | {{nula}} |
| 1 | {{jeden}} / {{jedna}} / {{jedno}} |
| 2 | {{dva}} / {{dve}} |
| 3 | {{tri}} |
| 4 | {{štyri}} |
| 5 | {{päť}} |
| 6 | {{šesť}} |
| 7 | {{sedem}} |
| 8 | {{osem}} |
| 9 | {{deväť}} |
| 10 | {{desať}} |

> **1 et 2 changent selon le genre** du nom qui suit :
> - {{jeden muž}} = un homme *(masculin)*
> - {{jedna žena}} = une femme *(féminin)*
> - {{jedno dieťa}} = un enfant *(neutre)*
> 
> - {{dva muži}} = deux hommes *(masculin)*
> - {{dve ženy}} = deux femmes *(féminin)*

## 🎯 À retenir

**Les chiffres 11–19** suivent un schéma simple : le chiffre de base (1–9) + **-násť**.

- 11 = {{jeden}} + -násť = {{jedenásť}}
- 15 = {{päť}} + -násť = {{pätnásť}}
- 19 = {{deväť}} + -násť = {{devätnásť}}

**20** est l'exception : {{dvadsať}} (et non *desat'*).
