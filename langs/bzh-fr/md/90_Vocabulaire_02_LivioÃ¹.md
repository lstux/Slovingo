# 🎨 Vocabulaire — Livioù (Couleurs)

---

## Les couleurs de base

| Brezhoneg | Français |
|---|---|
| gwenn | blanc |
| du | noir |
| ruz | rouge |
| glas | bleu *(et vert "naturel" : herbe, mer, arbres)* |
| gwer | vert *(couleur "artificielle", peinte ou teinte)* |
| melen | jaune |
| roz | rose |
| mouk, limestra | violet |
| orañjez, melen-ruz | orange |
| gell, kistin | marron |
| louet, gris | gris |
| rous | roux |

+ **Glas** et **gwer** se partagent le vert : *glas* pour le vert de la nature (l'herbe, un arbre, la mer, un œil vert), *gwer* pour un vert "fabriqué" — une peinture, un tissu, un objet teint.

---

## Phrases d'exemple

! Ruz eo an oto.
> La voiture est rouge.
> ruz = rouge

! Glas eo ar mor hiziv.
> La mer est bleue aujourd'hui.
> glas = bleu

! Ur roched wer he deus prenet.
> Elle a acheté une chemise verte.
> gwer = vert *(mutation après "ur roched", féminin)*

! Da betra servij al liv melen?
> À quoi sert la couleur jaune ?
> al liv = la couleur

---

## À retenir

✅ Douze couleurs de base, dont deux verts distincts (glas/gwer) et deux violets (mouk/limestra)
✅ Al liv = la couleur, al livioù = les couleurs
✅ Comme tout adjectif après un nom féminin singulier, une couleur peut se lénifier (ruz → ur roched ruz reste "ruz", mais gwer → wer)
