# 🇸🇰 Mémo 4 — Compter en slovaque

Les nombres reviennent partout : l'âge, l'heure, les prix, les quantités. Tu les croiseras dans presque chaque série. Voici de quoi s'en sortir dès le départ — la liste complète (jusqu'au million !) reste dans la bibliothèque si tu veux tout voir d'un coup.

---

# 1. De 0 à 20

| Číslica | Slovenčina |
|---:|---|
| 0 | nula |
| 1 | jeden / jedna / jedno |
| 2 | dva / dve |
| 3 | tri |
| 4 | štyri |
| 5 | päť |
| 6 | šesť |
| 7 | sedem |
| 8 | osem |
| 9 | deväť |
| 10 | desať |
| 11 | jedenásť |
| 12 | dvanásť |
| 13 | trinásť |
| 14 | štrnásť |
| 15 | pätnásť |
| 16 | šestnásť |
| 17 | sedemnásť |
| 18 | osemnásť |
| 19 | devätnásť |
| 20 | dvadsať |

> **1 et 2 changent selon le genre** :
> {{jeden muž}} = un homme · {{jedna žena}} = une femme · {{jedno dieťa}} = un enfant
> {{dva muži}} = deux hommes · {{dve ženy}} = deux femmes

---

# 2. Au-delà de 20

Les dizaines suivent le même principe :

| Číslo | Slovenčina |
|---:|---|
| 20 | dvadsať |
| 30 | tridsať |
| 40 | štyridsať |
| 50 | päťdesiat |
| 60 | šesťdesiat |
| 70 | sedemdesiat |
| 80 | osemdesiat |
| 90 | deväťdesiat |

Et pour les nombres entre deux dizaines, on colle simplement dizaine + unité, en un seul mot : {{dvadsaťjeden}} (21), {{štyridsaťdva}} (42)... Rien à apprendre par cœur ici, juste le réflexe d'assembler.

---

# 3. Dans une vraie phrase

! Koľko máš rokov?
> Quel âge as-tu ?
> Koľko = combien
> máš = tu as
> rokov = d'années

! Mám tridsať rokov.
> J'ai trente ans.
> Mám = j'ai
> tridsať = trente
> rokov = ans

! Koľko to stojí?
> Combien ça coûte ?
> Koľko = combien
> to = ça
> stojí = coûte
