# Grammaire - Les prépositions

Les prépositions slovaques imposent un cas grammatical (une déclinaison) au mot qui suit. Il n'est pas nécessaire de maîtriser toutes les déclinaisons pour commencer : retenir la préposition avec un exemple concret suffit pour l'instant.

## Vocabulaire essentiel

| Slovaque | Cas | Français |
|----------|-----|----------|
| v | locatif | dans / à (lieu où l'on est) |
| na | locatif / accusatif | sur / à |
| do | génitif | dans / vers (direction) |
| z | génitif | de / depuis (origine) |
| s / so | instrumental | avec |
| pri | locatif | près de |
| pred | instrumental | devant |
| za | instrumental / accusatif | derrière / dans (un délai) |
| o | locatif | au sujet de |
| k / ku | datif | vers / chez |

## Exemples

! Som v škole.
> Je suis à l'école.
> Som = je suis
> v škole = à l'école (dans l'école)
+ "V" indique un lieu où l'on se trouve (question "kde?" - où).

! Kniha je na stole.
> Le livre est sur la table.
> Kniha je = le livre est
> na stole = sur la table

! Idem do školy.
> Je vais à l'école.
> Idem = je vais
> do školy = vers l'école
+ Contrairement à "v" (position), "do" indique une direction, un mouvement vers un lieu (question "kam?" - vers où).

! Som z Francúzska.
> Je viens de France.
> Som = je suis
> z Francúzska = de France
+ "Z" indique une origine ou un point de départ.

! Idem s kamarátom.
> Je vais avec un ami.
> Idem = je vais
> s kamarátom = avec un ami

! Sedím pri okne.
> Je suis assis près de la fenêtre.
> Sedím = je suis assis
> pri okne = près de la fenêtre

! Auto je pred domom.
> La voiture est devant la maison.
> Auto je = la voiture est
> pred domom = devant la maison

! Mačka je za skriňou.
> Le chat est derrière l'armoire.
> Mačka je = le chat est
> za skriňou = derrière l'armoire

! Hovoríme o filme.
> On parle du film.
> Hovoríme = nous parlons
> o filme = du film (au sujet du film)

! Idem k lekárovi.
> Je vais chez le médecin.
> Idem = je vais
> k lekárovi = chez le médecin (littéralement : vers le médecin)
+ "K/Ku" s'utilise notamment pour dire qu'on va chez quelqu'un ou vers une personne.
