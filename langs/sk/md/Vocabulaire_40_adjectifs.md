## 1. Taille et dimension

| Slovenčina | Français |
|-----------|----------|
| veľký / veľká | grand(e) |
| malý / malá | petit(e) |
| dlhý / dlhá | long / longue |
| krátky / krátka | court(e) |
| vysoký / vysoká | haut(e), grand(e) (pour une personne) |
| nízky / nízka | bas(se), petit(e) (pour une personne) |

+ Pour parler de la taille d'une personne, on utilise "vysoký/vysoká" (grand) et "nízky/nízka" (petit), différents de "veľký/malý" utilisés pour les objets.

## 3. Décrire quelqu'un ou quelque chose

! Aký je tvoj nový byt?
> Comment est ton nouvel appartement ?
> aký je = comment est (masculin) · tvoj nový byt = ton nouvel appartement

! Je veľký a svetlý.
> Il est grand et lumineux.
> je = il est · veľký = grand · svetlý = lumineux

! Tá dievčina je veľmi vysoká.
> Cette fille est très grande.
> tá dievčina = cette fille · veľmi vysoká = très grande

+ "aký/aká/aké" (comment, quel) s'accorde en genre avec le nom qu'il qualifie, tout comme la réponse qui suit.

! Toto mesto je staré, ale veľmi pekné.
> Cette ville est vieille mais très belle.
> toto mesto = cette ville · staré = vieille · veľmi pekné = très belle

---

## ⚠️ Pièges pour les francophones

- Pour parler de la taille d'une personne, on emploie "vysoký/nízky" (haut/bas), pas "veľký/malý" qui concernent plutôt les objets ou les quantités.
- "ťažký" veut dire à la fois "lourd" (poids) et "difficile" (complexité) : le contexte permet de distinguer les deux sens.
- Tous ces adjectifs s'accordent en genre comme les couleurs et les émotions : -ý (masculin), -á (féminin), -é (neutre).
